# 06. Каталог машинных кодов ошибок API

Нормативный реестр `error.code` для всех ответов API (см. docs/04, §1). Правила:
код — `SCREAMING_SNAKE_CASE`, стабилен между версиями, документирован здесь до использования;
`message` всегда на русском и понятен пользователю; `details` — только нечувствительные данные.

## Auth (401)

| Код                      | Когда                                       |
| ------------------------ | ------------------------------------------- |
| `AUTH_INVALID_SIGNATURE` | Неверный HMAC initData                      |
| `AUTH_EXPIRED`           | `auth_date` вне replay window               |
| `AUTH_DEV_FORBIDDEN`     | Dev-auth запрошен вне development-окружения |
| `SESSION_EXPIRED`        | Сессия/токен истёк                          |

## Права и лимиты (403/404/429)

| Код              | Когда                                               |
| ---------------- | --------------------------------------------------- |
| `FORBIDDEN`      | Аутентифицирован, но без права на операцию          |
| `NOT_FOUND`      | Единая политика разглашения: чужое = несуществующее |
| `QUOTA_EXCEEDED` | Превышена квота проектов/хранилища/публикаций       |
| `RATE_LIMITED`   | Rate limit per user/project/player                  |

## Документ и ревизии (409/413/422)

| Код                  | Когда                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------- |
| `REVISION_CONFLICT`  | `baseRevision` не совпал с серверным                                                      |
| `SCHEMA_INVALID`     | Документ не прошёл Zod-схему                                                              |
| `GRAPH_BROKEN_REF`   | Ссылка на несуществующий node/entity/variable                                             |
| `HIERARCHY_CYCLE`    | parentId образует цикл                                                                    |
| `MIGRATION_FAILED`   | Документ устаревшей schemaVersion не мигрируется или его schemaVersion новее сервера      |
| `MUTATION_ID_REUSED` | Тот же `mutationId` уже применён к этому проекту с другим документом/`baseRevision` (409) |
| `DOCUMENT_TOO_LARGE` | Тело запроса или сериализованный документ больше лимита черновика (413)                   |

## Assets (413/422)

| Код                       | Когда                                                |
| ------------------------- | ---------------------------------------------------- |
| `ASSET_TOO_LARGE`         | Превышен лимит размера                               |
| `ASSET_TYPE_FORBIDDEN`    | MIME/magic bytes не в allowlist                      |
| `ASSET_PROCESSING_FAILED` | Worker не смог валидировать/превью                   |
| `ASSET_MISSING`           | Публикация ссылается на отсутствующий/не ready asset |

## Публикация (409/422)

| Код                           | Когда                                                            |
| ----------------------------- | ---------------------------------------------------------------- |
| `PUBLISH_VALIDATION_FAILED`   | Валидация графов/сцен не пройдена; `details.errors[]` обязателен |
| `PUBLISH_LINK_NOT_CONFIGURED` | Bot username не задан — честный отказ вместо фиктивной ссылки    |
| `ALREADY_UNPUBLISHED`         | Публичный alias уже снят                                         |

## Запросы (422)

| Код                 | Когда                                                                         |
| ------------------- | ----------------------------------------------------------------------------- |
| `VALIDATION_FAILED` | Тело/параметры запроса (не ProjectDocument) не прошли схему; `details.issues` |

## Runtime/Data Collections (403/422)

| Код                    | Когда                                          |
| ---------------------- | ---------------------------------------------- |
| `ACTION_NOT_PERMITTED` | Действие не в allowlist публичного runtime     |
| `DATA_POLICY_DENIED`   | read/write policy коллекции запрещает операцию |

## Инфраструктура (500/503)

| Код                   | Когда                                               |
| --------------------- | --------------------------------------------------- |
| `INTERNAL_ERROR`      | Непредвиденная ошибка сервера без отдельного кода   |
| `SERVICE_UNAVAILABLE` | Зависимость (БД и т.п.) недоступна; health degraded |

## Правило добавления

Новый код вводится только через PR к этому файлу с описанием триггера и HTTP-статуса.
Запрещено возвращать незадокументированные коды.
