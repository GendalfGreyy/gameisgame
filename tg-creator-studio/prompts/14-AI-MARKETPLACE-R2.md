# 14 — AI Creator, Marketplace и создательская экономика (опциональный R2)

Только после R1 и базовой модерации. Спроектируй AI Creator как **агента, использующего типизированные EditorCommands и schema validation**, а не генератор произвольного кода. Текстовый запрос → предложенный план изменений → визуальный diff → подтверждение автора → транзакция команд → Undo целой AI операции. Лимиты токенов, стоимость, безопасность, запреты, журнал операций, возможность отмены.

Marketplace: Asset/Template/Product manifest с лицензией, owner rights, preview sandbox, анти-malware, модерация, версии, отзывы/жалобы, авторские права, marketplace permissions. Платежные функции включай только после проверки действующих правил Telegram для цифровых товаров и Telegram Stars; серверная обработка статусов платежей и идемпотентность.

ACCEPTANCE: AI создает простую проверяемую 3D/2D сцену через валидные команды, плохой output отвергается без изменения проекта; template install работает, не исполняет произвольные scripts; все покупки и permissions проходят серверный аудит. Feature flags позволяют полностью отключить R2, не ломая R1.
